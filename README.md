## ✨ Features

- 📄 **Multiple PDF Viewer** — Open and view multiple PDFs seamlessly
- 📝 **Note Taking** — Take notes while studying or teaching
- 👨‍🏫 **Built for Educators** — Designed keeping teachers and students in mind
- 🎨 **Clean UI** — Simple and intuitive user interface
- ⚡ **Fast & Lightweight** — Smooth performance on all Android devices
